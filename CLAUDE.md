# Project: wf-minimal-code-starter

Webflow TypeScript integration. Built code is hosted on CDN (Vercel), injected into Webflow via one `<script src="main.js">` tag in site-wide custom code. Each Webflow page sets `data-page="name"` on `<body>`.

## Commands

| Command | Purpose |
|---|---|
| `bun run dev` | Vite dev server with HMR on localhost:3000 |
| `bun run build:pages` | esbuild production build — per-page ESM + shared chunks |
| `bun run preview:pages` | Build + serve dist locally on :4173 |
| `bun run lint` | ESLint with auto-fix |

## Architecture

```
src/
  features/global/   ← runs on every page (imported automatically)
  features/[page]/   ← page-specific features
  pages/[page].ts    ← page entry; imports its own features
  main.ts            ← dev-only entry (import.meta.glob), never changes
```

### Production output (`dist/`)

- `main.js` — tiny IIFE loader with embedded page→file manifest; add to Webflow site-wide
- `[page].[hash].js` — ESM page entry (browser resolves chunk imports from CDN automatically)
- `chunks/[hash].js` — shared code extracted by esbuild (GSAP, shared utilities)

## Conventions

- Page name must match the `data-page` attribute value AND the filename in `src/pages/`
- Global features live in `src/features/global/` — auto-imported into every page bundle
- Never edit `dist/` manually — always rebuild via `bun run build:pages`
- `console.*` calls are stripped in production builds; safe to use freely in dev
